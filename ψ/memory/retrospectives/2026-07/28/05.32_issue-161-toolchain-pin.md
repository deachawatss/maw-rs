## AI Diary

I began from the issue's explicit 1.91.0 floor and treated it as the natural
concrete build pin. That was a reasonable first interpretation, but the first
CI run made the distinction between a compiler floor and a usable lint gate
unavoidable: 1.91.0 built the entire workspace, passed tests, and linked the
MUSL binary, yet its Clippy introduced or enabled diagnostics against existing
source. [→ AGENT DECISION] I chose the minimum successful build compiler as
the initial CI pin before checking whether the repository's mandatory Clippy
gate was also compatible with it. The recovery was not to silence lint errors
or expand scope into unrelated source files. I used the issue's allowance for a
concrete pin above the floor, checked the latest successful main CI version,
and pinned 1.97.1 while leaving rust-version at 1.91.0. I also had to rebase
after main moved during the long CI run. Re-running the full gate after that
rebase was slow but necessary; the final evidence applies to the actual PR
head, not an earlier tree.

## Honest Feedback

The session had three clear friction points. First, CI is intentionally the
only Cargo gate for L2 work, so correcting the first pin required waiting for
two long remote runs rather than a quick local reproduction. That trade-off is
correct for this repository but makes exact configuration changes expensive.
Second, `maw pr` re-ran the no-match search from delivery metadata and rejected
the raw `rg` command because no results correctly return exit code 1; the
metadata needed a shell predicate that represents the asserted condition.
Third, the GitHub CLI's project-classic deprecation caused PR edit commands to
fail even though PR creation worked, requiring the REST endpoint for updates.
The unexpected `rustup show active-toolchain` download was another reminder
that a seemingly observational command can mutate the local toolchain cache
when a new override is present.

## Lessons Learned

- Treat an MSRV and a pinned CI toolchain as different contracts: the first is
  the lowest compiler that builds the product, while the second must also pass
  every enforced quality gate.
- When an assertion is that a search has no matches, encode it as a command
  that exits zero on no matches before placing it in automated verification
  metadata.
