## Lessons Learned

- Put CLI recovery guidance in the returned error whenever the command wrapper discards buffered stdout on failure.
- For a force flag, test both the intended escape hatch and the safety guard that must remain enforced; “force” should not silently widen unrelated permissions.
- When local execution is prohibited, preserve test-first structure and make CI dependency explicit in both the PR body and handoff.
